# Borrador para LinkedIn

Me alegra compartir **Calmwaters Decants**, una landing page creada para una tienda de perfumes originales en formato decant.

El objetivo del proyecto es que descubrir una fragancia sea simple: explorar el catálogo, filtrar por familias olfativas, revisar notas y acordes, elegir un formato y consultar el pedido por Instagram.

Trabajé en una experiencia responsive, con una estética elegante y componentes interactivos. El proyecto está desarrollado con **React, Vite, Tailwind CSS y Framer Motion**.

🔗 Demo en vivo: https://calmwaters-decants.netlify.app/  
💻 Código: https://github.com/fatekiDev/calmwaters-decants
