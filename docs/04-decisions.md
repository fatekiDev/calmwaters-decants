 # Decisiones técnicas

| Decisión | Elección | Motivo |
|----------|----------|--------|
| Framework | React (Vite) | Componentes reutilizables, build rápido |
| Estilos | Tailwind CSS | Desarrollo rápido y consistente |
| Animaciones | Framer Motion | Modal y flipcard fluidos |
| Datos | Archivo `perfumes.js` | Agregar perfumes sin tocar componentes |
| Venta | Enlace a Instagram | Requisito del cliente en v1 |
| Deploy | Vercel / Netlify | Gratis, conectado a GitHub |
| Enfoque | Mobile-first | El tráfico viene de Instagram |
